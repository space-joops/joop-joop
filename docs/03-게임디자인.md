# 줍줍! — 게임디자인 문서

> GitHub 이슈 [#3](https://github.com/space-joops/joop-joop/issues/3)의 산출물.
> 여기 정의된 수치가 곧 `js/config.js`의 단일 진실(Single Source of Truth)이다.
> 밸런스를 바꿀 때는 이 문서와 config를 함께 갱신한다.

## 1. 공간 구조

화면 중앙 아래쪽에 **지구**가 있고, 그 둘레에 동심원 궤도 2개가 있다.

```
        · 바깥 궤도 (반지름 R_out)
      ·   안쪽 궤도 (반지름 R_in)
    ·   ⊙ 지구
```

- 줍은 항상 두 궤도 중 하나 위에서 **반시계 방향**으로 공전한다.
- 오브젝트(쓰레기·파편)도 궤도 위에 스폰되어 줍 쪽으로 다가온다
  (실제로는 줍이 앞으로 나아가는 것 — 상대 운동).
- 탭 입력 시 줍이 다른 궤도로 **이징 곡선을 그리며 전환**한다 (전환 시간 0.18초).

## 2. 오브젝트

| 오브젝트 | 역할 | 판정 | 효과 |
|---|---|---|---|
| 🗑️ 우주 쓰레기 (초록 계열) | 수집물 | 닿으면 획득 | +점수, 콤보 +1, 조각 +1 |
| ⚠️ 위험 파편 (빨강, 뾰족) | 회피물 | 닿으면 피격 | 생명 -1, 콤보 0, 잠시 무적 |
| ✨ 별조각 (노랑, 희귀) | 보너스 | 닿으면 획득 | 조각 +5, 피버 게이지 크게 충전 |

- 쓰레기 종류는 시각 다양성용 3종(캔, 볼트, 파편)이며 효과는 동일하다.
- 생명은 3개. 0이 되면 게임 오버.
- 피격 후 무적 1.5초 (줍이 깜빡인다).

## 3. 점수·콤보

- 기본 점수: 쓰레기 1개 = **10점 × 콤보 배율**.
- 콤보 배율: 콤보 5마다 +0.5배 (1.0 → 1.5 → 2.0 …, 최대 5.0배).
- **니어미스 보너스**: 위험 파편을 반경 1.6배 이내로 스치면 +5점, 조각 +1.
  위험에 가까이 갈수록 이득 — 리스크/리워드의 핵심.
- 피격 시 콤보는 0으로 리셋 (조각·점수는 유지).

## 4. 피버 모드

- 피버 게이지: 쓰레기 +6%, 별조각 +25%, 시간이 지나면 서서히 감소(-2%/초).
- 100% 도달 시 **피버 발동, 6초간**:
  - 점수 2배, 위험 파편이 전부 별조각으로 변신 (화면이 안전해진다 = 해방감)
  - 자석 효과: 근처 수집물이 줍에게 빨려온다
  - 배경 연출 강화 (네온 그라데이션, 스캔라인 가속)
- 종료 후 게이지 0부터 다시.

## 5. 난이도 곡선

시간 `t`(초)에 따라 회전 속도와 스폰 밀도가 오른다. 상한이 있어 무한히 어려워지지 않는다.

| 항목 | 시작값 | 증가 | 상한 |
|---|---|---|---|
| 공전 각속도 | 1.1 rad/s | +0.018/s | 2.6 rad/s |
| 스폰 간격 | 0.9초 | -0.01초/s | 0.45초 |
| 위험 파편 비율 | 15% | +0.45%p/s | 40% |

- 첫 10초는 위험 파편이 나오지 않는다 → 튜토리얼 없이 첫 판에서 학습.
- 별조각 확률: 위험 비율을 제외한 나머지 중 8%.

## 6. 경제 — 조각과 스킨 해금

조각(💠)은 판이 끝나도 누적되는 영구 화폐다. localStorage에 저장한다.

스킨 6종은 **원작 스프라이트의 액센트 6색 변형**(`JOOP_SHEET_COLORS`)을 그대로 계승한다.
정확한 hex 값은 [04-아트디자인](./04-아트디자인.md) §3-2 참고.

| 스킨 id | 이름 | 액센트 컨셉 | 가격 |
|---|---|---|---|
| `joobi` | 주비 | 형광 그린 — 첫 반려 줍 | 무료 |
| `amber` | 앰버 | 호박색 계기판 감성 | 100 |
| `cyan` | 시아 | 시안 네온, 시원한 성격 | 250 |
| `magenta` | 마젠 | 마젠타, 새침한 멋쟁이 | 450 |
| `lime` | 라임 | 라임 소다처럼 통통 튐 | 700 |
| `gold` | 골디 | 골드 — 전설의 청소 요원 | 1000 |

- 가격은 "가볍게 몇 판이면 하나, 다음 것은 조금 멀리" 곡선.
- 스킨은 색상 + 소소한 개성(눈 모양·안테나 등)이 다르다. 성능 차이는 없다 (공정성).

## 7. 화면 흐름

```
타이틀 (탭하여 시작, 스킨 선택, 음소거)
  → 플레이 (HUD: 점수·콤보·피버 게이지·생명)
  → 게임 오버 (점수·최고기록·획득 조각, "한 판 더" 1탭)
  → (반복)
```

- 게임 오버 → 재시작 입력까지 어떤 확인 창도 없다.
- 최고기록 갱신 시 결과 화면에서 축하 연출.

## 8. 조작 정리

| 입력 | 동작 |
|---|---|
| 탭 / 클릭 / 스페이스 | 궤도 전환 (플레이 중) · 시작/재시작 (메뉴) |
| M 키 / 스피커 버튼 | 음소거 토글 |

## 9. 라이브 운영 기능 (M5)

### 9-1. 점수 공유 (이슈 #15)

결과 화면의 **📡 자랑하기** 버튼. 시장분석 §5 발견성 리스크 대응.

- 공유 카드: 1080×1080 PNG. 게임의 실제 렌더 코드(`drawJoopPortrait`)로 그려
  브랜드가 인게임과 일치한다. 선택 중인 스킨이 카드에 나온다 (스킨 = 자랑거리).
- 폴백 사다리: 이미지 공유(모바일) → 텍스트+URL 공유 → 클립보드 복사(데스크톱).

### 9-2. 출석 보너스 (이슈 #16)

시장분석 §5 리텐션 리스크 대응 — 매일 돌아올 이유.

| 항목 | 값 |
|---|---|
| 지급 시점 | 하루(로컬 자정 기준) 첫 접속 |
| 기본 지급 | 20조각 |
| 연속 출석 | 하루마다 +10조각 |
| 상한 | 50조각 (4일차부터) |
| 스트릭 리셋 | 하루라도 건너뛰면 1일차로 |

스킨 경제와의 관계: 출석만으로 앰버(100)까지 5일. 플레이 보상이 여전히 주 수입원.

### 9-3. 배경 위상 (이슈 #17)

오래 버틸수록 하늘이 변한다 — 숙련의 시각적 보상.

| 위상 | 시작(초) | 연출 |
|---|---|---|
| 심우주 | 0 | 기본 배경 |
| 오로라 | 45 | 상단 시안, 하단 그린의 옅은 커튼 |
| 여명 | 100 | 상단 앰버, 지평선 핑크 |

- 전환은 8초에 걸쳐 크로스페이드. 화면 중앙(플레이 영역)은 항상 맑게 유지.
- 피버 연출이 우선 — 피버 중에는 위상 오버레이를 쉬게 한다.

## 10. 애착 시스템 (M6, 이슈 #18)

첫 화면을 "메뉴"에서 **"내 줍을 만나는 곳"** 으로 바꾼다.
원작의 유대(Bond) 시스템을 계승하되, 원작에서 저장되지 않던 것을 영속화한다.

### 10-1. 이름 짓기

원작의 "분양 + 유니크 이름" 규칙 계승 (단, 서버가 없으니 유니크 검증은 없음).

- 기본 이름 **"줍이"**. 첫 화면 ✏️ 버튼으로 언제든 변경.
- 1~12자 (모바일 입력 부담 고려해 원작 20자보다 짧게). 앞뒤 공백 제거.
- 이름은 첫 화면과 결과 화면("OO의 임무 종료")에 나온다.

### 10-2. 유대 (Bond)

| 항목 | 값 |
|---|---|
| 유대 점수 | 누적 수거 쓰레기 1개 = 1점, 쓰다듬기 1회 = 5점 |
| 단계 (원작 명칭 그대로) | 0점 아직 낯가려요 → 150점 친해지는 중 → 500점 든든한 동료 → 1200점 한 몸처럼 |

- 단계는 첫 화면 이름 옆 칩으로 표시. 단계별로 인사말 대사 풀이 달라진다.
- 원작 공식(caught×5 − hits×12)은 한 판용이라, 누적형으로 재설계했다.
  감점은 두지 않는다 — 애착 시스템에서 벌은 역효과.

### 10-3. 쓰다듬기

- 첫 화면에서 줍을 탭하면: 기쁨 표정 + 바운스 + 하트 팝업 + **"삐링~" 오마주 사운드**
  (원작 큐브샛 사출 시그니처 C6→F6→C7 아르페지오).
- 쓰다듬기 1회 = 유대 +5점. 상한 없음 — 쓰다듬고 싶은 만큼.
- 반응 대사는 말풍선에 랜덤 표시.

### 10-4. 첫 화면 구성 (이슈 #19)

```
[말풍선 — 유대 단계별 인사말]
[큰 줍 — 라이브 렌더: 깜빡임·호버링·선택 스킨·탭하면 쓰다듬기]
[컴팩트 패널 — 타이틀·이름(✏️)·유대 칩·스킨·최고기록·발사!]
```

### 10-5. 유대 상승 축하 (이슈 #21)

- 쓰다듬기로 단계가 오르면 **그 자리에서 즉시** 축하: 축하 대사 + 폭죽 + 팡파레 + 바운스.
- 플레이(누적 수거)로 단계가 오르면 판 도중에 끊지 않고, **기지로 돌아온 순간** 축하한다
  (`pendingTierUp` — 축하는 줍과 마주 봤을 때 해야 의미가 있다).

### 10-6. 조는 줍 (이슈 #22)

다마고치 감성 — 반려는 가만히 둬도 살아 있어야 한다.

| 항목 | 값 |
|---|---|
| 잠드는 조건 | 첫 화면에서 20초 무입력 |
| 잠든 모습 | 감은 눈(내리감은 곡선) + 느린 호버링 + 💤 2.5초마다 |
| 깨우기 | 줍 탭(기상 대사 + 기쁨) 또는 아무 상호작용(스킨·이름 편집) |
| 잠든 중 쓰다듬기 | 깨우기로 처리 — 쓰다듬기 카운트 없음 (미안하니까) |

### 10-7. 대사 확장 (이슈 #23)

- **스킨(도색) 성격 대사**: 도색마다 2개씩, 인사말에 30% 확률로 혼입.
  주비(첫 반려의 순수함) · 앰버(계기판 감성) · 시아(쿨함) · 마젠(새침) ·
  라임(에너지) · 골디(전설 요원 허세).
- **히든 대사**: 유대 "한 몸처럼" 도달 후 인사말의 10%로 나오는 진심 대사 3종.
  자주 보이면 히든이 아니다 — 확률을 낮게 유지한다.
