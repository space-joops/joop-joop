# 줍줍! (Joop Joop!) — 기획서

> GitHub 이슈 [#1](https://github.com/space-joops/joop-joop/issues/1)의 산출물.
> 원작 [joop-03 (줍스)](https://github.com/space-joops/joop-03) 세계관의 파생 아케이드 게임.

## 1. 비전

**"3초 만에 이해하고, 3분 만에 애착이 생기는 궤도 청소 게임."**

원작 줍스는 다마고치(방치형 육성) + 아케이드가 결합된 협력 게임이다.
줍줍!은 그 세계관에서 **아케이드의 재미만 증류**해, 누구나 설치 없이
브라우저에서 바로 빠져들 수 있는 원터치 게임으로 만든다.

두 가지를 극대화한다:

| 축 | 방법 |
|---|---|
| **게임성** | 원터치 조작, 콤보·피버의 리스크/리워드, 점진적 가속, "한 판 더" 루프 |
| **귀여움** | 큰 눈망울의 줍, 표정 상태기계, 스쿼시&스트레치, 통통 튀는 효과음 |

## 2. 세계관 — 원작 계승

원작의 설정을 그대로 잇는다. 새로 지어내지 않는다.

- 가까운 미래, 인류는 화성 개발에 성공했고 우주여행이 일상이 되었다.
- 그러나 **케슬러 신드롬**(파편이 파편을 낳는 연쇄 충돌)이 현실화되어
  지구 저궤도가 위험해졌다.
- 지구 시민들은 반려형 청소 로봇 **줍스(Joops)** 를 분양받아 궤도로 발사했고,
  전 지구적 협력으로 우주를 청소하고 있다.
- **줍줍!은 그중 한 마리 줍의 하루** — 궤도에서 쓰레기를 줍는 순간을
  아케이드로 담아낸 이야기다.

디자인 언어도 원작의 **카세트퓨처리즘**(1970~80년대가 상상한 미래,
형광 그린/앰버 모노크롬, CRT 스캔라인, 관제 콘솔 미감)을 계승한다.

## 3. 핵심 게임 루프

```
탭(궤도 전환) → 쓰레기 줍줍(점수+콤보) → 위험 파편 회피
   → 콤보 유지 → 피버 모드(폭발적 수확) → 게임 오버
   → 조각으로 새 줍 친구 해금 → "한 판 더"
```

- **조작은 단 하나**: 탭/클릭/스페이스바 = 안쪽 ↔ 바깥쪽 궤도 전환.
- **인지 부하는 둘 뿐**: 초록(줍는다) / 빨강(피한다).
- **세션 길이**: 30초~2분. 실패해도 즉시 재시작(1탭).

## 4. 게임성 설계 원칙

1. **첫 판에서 배우게 한다** — 튜토리얼 화면 없이, 첫 10초는 느리게 시작.
2. **실패는 빠르게, 재도전은 더 빠르게** — 게임 오버 → 재시작까지 1탭.
3. **리스크/리워드** — 위험 파편 가까이 스치면 더 많은 조각(니어미스 보너스).
4. **성장 체감** — 시간에 따른 가속 + 콤보 배율로 "이번 판은 더 잘했다"를 숫자로 확인.
5. **수집욕** — 판마다 모은 조각이 누적되어 줍 스킨을 해금. 애착의 고리.

## 5. 귀여움 설계 원칙

1. **캐릭터가 항상 반응한다** — 줍기(기쁨), 충돌(아야), 피버(반짝), 대기(깜빡임·호버링).
2. **물리적 애교** — 궤도 전환 시 스쿼시&스트레치, 착지 바운스.
3. **소리의 귀여움** — 통통 튀는 칩튠 효과음(WebAudio 합성, 에셋 없음).
4. **이름 있는 친구들** — 스킨은 단순 색상이 아니라 이름과 성격이 있는 줍 친구들.

## 6. 타깃 / 플랫폼

- **타깃**: 짧은 휴식 시간에 가볍게 즐기는 캐주얼 유저. 게임 경험 불문.
- **플랫폼**: 모바일 세로 화면 우선(원작 원칙 계승), 데스크톱 겸용.
- **배포**: 웹(Vercel). 설치·로그인·서버 없음. 진입 장벽 0.

## 7. 범위 (MVP)

**포함**: 코어 루프, 콤보/피버, 니어미스, 스킨 해금 4종+, 로컬 최고기록,
칩튠 사운드, 타이틀/결과 화면.

**제외** (원작 본편의 영역): 서버 랭킹, 계정, 다마고치 육성, 발사 시퀀스, i18n.
