# 줍줍! — 아트디자인 문서

> GitHub 이슈 [#4](https://github.com/space-joops/joop-joop/issues/4)의 산출물.
> 원작 joop-03 저장소의 스프라이트·디자인 토큰을 실측 분석해 계승한다.
> (출처: `public/game/joop-sheet-*.png` 픽셀 실측, `docs/design/design-tokens.md`, `app/globals.css`)

## 1. 세계관 불변 규칙 (원작에서 계승, 절대 어기지 않는다)

1. **줍스는 무기가 없다** — 집게 팔·자석·트랙터 빔으로 "줍는" 로봇. 파괴가 아니라 청소.
2. **앰버 비콘은 브랜드 마크** — 안테나 끝 구슬은 어떤 스킨에서도 앰버(`#ffb23e`) 고정.
3. **CRT 화면은 검정이 아니다** — 액센트 색으로 미세하게 틴트된 근흑색.
4. **투톤 위계** — 앰버 = 수치·제목·게이지 / 그린 = 본문·CTA.
5. **형광색 배경 위 텍스트는 `--color-bg`** (`#030a05`) 전경으로.
6. 모바일 세로 전용, safe-area 준수.

> 표기 참고: 원작에서 개체 명칭은 한국어 '줍스', 영문 소문자 'joop'이다.
> 본작은 아케이드 톤에 맞춰 애칭 **'줍'** 을 사용한다 (문서에 명시된 의도적 선택).

## 3. 줍 캐릭터 스펙 (원작 스프라이트 정본 계승)

원작 정본은 **흉상형**: 둥근 사각 CRT 헤드 + 좌우 귀 포드 + 얇은 안테나(끝 앰버 구슬)
+ 작은 흉부(LED 3개) + 사다리꼴 하부 노즐. 본작은 이 구조를 Canvas 2D 벡터로 재구현한다
(스프라이트 이미지 대신 코드 드로잉 — 스킨 색상을 프로그램으로 만들기 위해).

### 3-2. 액센트 6변형 = 스킨 (원작 `JOOP_SHEET_COLORS` 그대로)

액센트는 눈·입·화염·트랙터 빔·LED에 적용. 화면 배경은 액센트 hue 틴트 근흑색.

| 스킨 id | 이름 | 액센트 | CRT 화면 배경 | 해금 가격(조각) |
|---|---|---|---|---|
| `joobi` | 주비 | `#39ff14` | `#0b290d` | 무료 (첫 반려 줍) |
| `amber` | 앰버 | `#ffb000` | `#18240c` | 100 |
| `cyan` | 시아 | `#2de2e6` | `#0a271b` | 250 |
| `magenta` | 마젠 | `#ff2e97` | `#181b16` | 450 |
| `lime` | 라임 | `#a0ff70` | `#122913` | 700 |
| `gold` | 골디 | `#ffd25e` | `#182612` | 1000 |

> 원작에서 `gold` 시트는 DB 팔레트에 대응이 없어 잉여였다.
> 본작에서 최고가 스킨으로 살려 쓴다 (파생작이 부채를 자산으로).

### 3-3. 표정 상태기계 (원작 폴백 렌더의 표정 규칙 계승 + 확장)

| 상태 | 눈 | 연출 | 발동 |
|---|---|---|---|
| `idle` | 네모 눈 2개, 3~5초마다 가로 대시로 깜빡 | 둥실 호버링 | 평상시 |
| `happy` | `^` 웃는 눈 | 살짝 점프(스쿼시&스트레치) | 수집 직후 0.35초 |
| `hurt` | `×` 눈 | 셰이크 + danger 색 글로우 | 피격 직후 |
| `fever` | 별 모양 눈 | 무지개빛 글로우, 화염 최대 | 피버 중 |

- 궤도 전환 순간: 이동 방향으로 몸이 늘어났다 줄어드는 **스쿼시&스트레치** (귀여움 핵심).
- 하부 노즐 화염: 평상시 작은 눈물방울형, 피버 시 커짐. 색은 액센트.

## 4. 오브젝트 시각 규칙

색약 유저도 구분할 수 있게 **색 + 형태 + 링** 3중 단서를 쓴다 (원작 식별 훈련의 규칙).

| 오브젝트 | 색 | 형태 | 추가 단서 |
|---|---|---|---|
| 우주 쓰레기 | primary `#35e07a` 발광 | 캔/볼트/패널 3종 실루엣 | — |
| 위험 파편 | danger `#ff5c77` 발광 | 5갈래 가시, 회전 | **점선 경고 링** (원작 위험물 규칙) |
| 별조각 | secondary `#ffb23e` 발광 | 4갈래 별, 맥동 | — |

## 5. 배경

- **지구**: 원작 브랜드 심볼(경위도 그리드 지구)을 따른다 — surface `#0a1c10` 원판에
  grid `#1e5a46` 경위도 선, 가장자리 그린 대기광. 파란 바다 지구가 아니라 **관제 화면 속 지구**.
- **궤도 링**: 점선 원 2개, 점선이 흘러 "세계가 도는" 느낌. primary 28% 투명도.
- **별**: fg 색 계열 픽셀 점 90개, 오프스크린 1회 생성.
- **스캔라인**: CSS 오버레이 (3px 주기, 알파 0.14 근처 — 원작 `--scanline-alpha` 준수).

## 6. UI

- 점수·계기: 모노스페이스 + 넓은 자간(원작 "모노 = 세븐세그먼트 대체" 원칙), 앰버 + 글로우.
- 버튼: 두꺼운 베젤 물리 버튼. CTA는 그린 배경 + `#030a05` 텍스트 (대비 원칙).
- 패널: surface 계열 반투명 + 그린 글로우 테두리.
