# 줍줍! (Joop Joop!) 🛰️

**▶ 지금 플레이하기: https://joop-joop.vercel.app**

> **space-joops 유니버스**의 궤도 청소 아케이드 게임.
> 원작 [joop-03 (줍스)](https://github.com/space-joops/joop-03)의 세계관을 잇는 파생작입니다.

## 한 줄 소개

케슬러 신드롬으로 위험해진 지구 저궤도 — 반려 청소 로봇 **줍(Joop)** 과 함께
탭 한 번으로 궤도를 넘나들며 우주 쓰레기를 줍는 **원터치 아케이드 게임**입니다.

## 세계관 (원작 계승)

- 가까운 미래, 인류는 화성 개발에 성공했지만 우주 쓰레기가 연쇄 충돌을 일으키는
  **케슬러 신드롬**이 현실이 되었다.
- 지구 시민들은 반려형 청소 로봇 **줍스(Joops)** 를 궤도로 발사해 다 함께 우주를 청소한다.
- 이 게임은 그중 한 마리의 줍이 되어, 오늘도 궤도 위 쓰레기를 줍줍하는 이야기다.

## 플레이 방법

- **탭 / 클릭 / 스페이스바** — 줍이 안쪽 ↔ 바깥쪽 궤도를 전환합니다.
- 🗑️ **우주 쓰레기**를 주우면 점수와 콤보가 오릅니다.
- ⚠️ **위험 파편**에 부딪히면 아야! 콤보가 끊깁니다.
- 콤보를 쌓아 **피버 모드**를 발동시키고, 모은 조각으로 새로운 줍 친구를 해금하세요.

## 개발

정적 웹 게임입니다. 빌드 과정이 없어 아무 정적 서버로나 열 수 있습니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```
